CasADiCodegen.jl: Julia code generation for CasADi functions

CasADiCodegen.jl is a package for generating plain Julia code from the functions of CasADi, the framework for symbolic modelling and algorithmic differentiation. A model is built and differentiated with CasADi, through the Julia front end of CasADi that the package includes, and CasADiCodegen.jl then emits the model and its derivatives as Julia functions, which run without CasADi and accept Julia arrays, static arrays, sparse matrices and the dual numbers of ForwardDiff.jl.

Features include:

  • Julia functions for the current session with build_function, or a Julia module on disk with generate_julia, each with an out-of-place and an in-place form.
  • Models that were built in Python, MATLAB or C++ and saved by CasADi, and models written as generic Julia code, which a number type traces into CasADi.
  • Calls to Julia functions inside a model, with derivatives from Julia functions or from an automatic differentiation backend.
  • Integrators, rootfinders and optimization solvers inside a model, which the generated code solves with the SciML packages.
  • CasADi functions as the functions of SciML problems: ODEFunction, NonlinearFunction and OptimizationFunction.

A CasADi function maps a fixed number of inputs to a fixed number of outputs,

\[(y_1, \dots, y_m) = f(x_1, \dots, x_n),\]

where each input $x_i$ and each output $y_j$ is a matrix with a fixed sparsity pattern. The outputs can contain derivatives of other outputs, such as a Jacobian $\partial y_1 / \partial x_1$ or a Hessian, which CasADi forms from the expression graph before the code is generated.

When to use CasADiCodegen.jl

CasADiCodegen.jl is the right choice when a model is defined with CasADi, or exists already in a CasADi file, and the model and its derivatives must run as Julia code: in a simulation, in an optimization with a Julia solver, or inside a SciML problem. A model written as generic Julia code enters CasADi by tracing, with the number type CasADiCodegen.Traced, so that one package serves both kinds of model; the interface of build_function follows that of Symbolics.jl. To evaluate a model with CasADi itself, in C or through its solvers, use the front end alone or the code generation of CasADi for C.

Installation

The package supports Julia 1.12 and 1.13. Install it from GitHub:

pkg> add https://github.com/EllissoideRotondo/CasADiCodegen.jl

The binaries of CasADi 3.8.1 and its Julia front end come with the package.

Contributing

  • Report bugs and request features on the issue tracker.
  • Before opening a pull request, run the test suite with julia --project=. -e 'using Pkg; Pkg.test()' from the repository root. Each group of tests is a file test/test_<group>.jl, and Pkg.test(; test_args = ["mx", "root"]) runs two groups. On Julia 1.12, also pass julia_args = ["--check-bounds=auto"] (see Keep bounds checks off in tests).
  • To build this manual, run julia --project=docs -e 'using Pkg; Pkg.instantiate()' and then julia --project=docs docs/make.jl from the repository root. The examples run during the build, and the pages are written to docs/build/.
