How an integrator is differentiated

This page explains what CasADi and the generated code do for the derivatives of a function made by CasADiCodegen.integrator: how forward sensitivities grow with the order of the derivative, why each arc is integrated once, what free times cost, and when the adjoint equations are the better choice. It is meant for a reader who wants to know where the time of a differentiated integrator goes.

Forward sensitivities

CasADi differentiates F to any order, because its Jacobian is a second integrator for the state with its sensitivity matrices, whose right side CasADi builds symbolically. Each of these integrators takes the initial state and the parameters of the first one, and integrates the derivatives by those only, so the number of states grows by the same factor at each order: 4 states and 1 parameter give 24 states for the Jacobian and 144 for the second derivative. The generated code reuses the state of the solver in each Julia task, and the table gives one measurement for the planar two-body problem.

OutputsTime per callMemory per call
Final state22 µs0.7 kB
Final state and its Jacobians by the initial state and by the parameter59 µs3.6 kB
The above and the second derivative by the initial state164 µs17 kB

An arc is one integration between two times. When a generated function needs the final state and its Jacobian, the call for the state runs the integration with the sensitivities and keeps its result, which the call for the Jacobian then takes, so that each arc is integrated once. This holds for any number of arcs in one function, and a function that needs the state alone integrates the state alone. The state from the integration with the sensitivities agrees with the state of an integration without sensitivities to the tolerances of the solver and not to the last digit, because the sensitivities take part in the step size control, as the partial derivatives of dual numbers do.

Free times

With free times, the derivative by the final time is the right side at the final state. For a model without the time in its right side, the derivative by the initial time is the opposite of that value, so free times add no state to the integration; a model with the time in its right side adds one column of sensitivities for the initial time.

Adjoint equations

The sensitivity matrices cost one integration of the state for each initial state and each parameter, which is more work than the gradient of one number by many parameters needs. With adjoint = true, a reverse derivative comes instead from an integrator of the adjoint equations, which runs from the final time back to the initial time and whose number of states does not grow with the number of parameters; its accuracy is that of the backward integration of the state. Forward derivatives and the derivatives of higher order still use the sensitivities.

For a model with algebraic states, the adjoint equations have the mass of the model, so the multipliers of the algebraic states are algebraic too. A seed, which is the vector that a reverse derivative multiplies with the Jacobian, on a final algebraic state first goes, through the algebraic equations at the final time, to the other final states, the parameters and the final time, which costs one linear solve.
